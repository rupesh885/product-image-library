# Product Image Library

A catalog of individual product images for the R&J Import Export product catalog.

## Image policy
- One file per product; no multi-product collages as product assets.
- Filenames follow the product IDs in `products.csv`.
- Use category folders and consistent 1200×1200 product photography.

## Categories
- Indian-Spices
- Fresh-Fruits
- Pulses-Grains
- Fresh-Vegetables
- Textiles-Garments
- Industrial-Chemicals
- Pharmaceutical-Drugs

Image generation and upload will proceed one product at a time.
